# React Modal (БЭМ)

Пример компонента модального окна на React с использованием методологии БЭМ и состояния.

## Описание

Этот проект демонстрирует, как реализовать модальное окно на весь экран с тёмным фоном, используя React и CSS по БЭМ. Модальное окно открывается по кнопке и закрывается по клику вне окна или на крестик.

## Как запустить

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите проект:
   ```bash
   npm run dev
   ```
3. Откройте в браузере адрес, указанный в терминале (обычно http://localhost:5173).

## Структура

- `src/App.jsx` — основной компонент приложения, содержит логику открытия/закрытия модального окна и сам компонент Modal.
- `src/App.css` — стили для модального окна и кнопки, оформленные по БЭМ.
- `public/` — статические файлы.
- `index.html` — точка входа для приложения.

## Особенности
- Модальное окно реализовано как отдельный компонент.
- Управление открытием/закрытием через React useState.
- Стилизация по БЭМ: `.modal`, `.modal__content`, `.modal__close`, `.modal__title`, `.modal__text`.
- Закрытие по клику вне окна или на крестик.
